# Code of Conduct · قواعد التعامل

## English

Be kind and respectful. Disagree with ideas, not with people. No harassment, insults, hate speech or spam. Assume good intent, and help newcomers. Maintainers may edit or remove comments, issues and PRs that break these rules, and may block people who keep breaking them. To report a problem, open an issue or use GitHub's report feature.

## بالعربي

خليك محترم ولطيف. اختلف عالأفكار مو عالأشخاص. ممنوع التحرش والشتائم وخطاب الكراهية والسبام. افترض النية الحسنة وساعد الجداد. صاحب المشروع بيقدر يعدّل أو يحذف أي تعليق أو issue أو PR بيخالف هالقواعد، وبيقدر يحظر اللي بيكرر المخالفة. لتبلّغ عن مشكلة افتح issue أو استعمل خاصية الإبلاغ بـ GitHub.
